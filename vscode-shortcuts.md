# VS Code Shortcuts Cheatsheet

> Speed up your coding with these essential shortcuts.

## General
| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + P` | Command Palette (most important!) |
| `Ctrl + P` | Quick file open |
| `Ctrl + ,` | Open Settings |
| `Ctrl + `` ` | Toggle terminal |
| `Ctrl + B` | Toggle sidebar |
| `Ctrl + Shift + E` | Explorer panel |
| `Ctrl + Shift + G` | Source control (Git) |
| `Ctrl + Shift + X` | Extensions |
| `Ctrl + Shift + F` | Search across all files |
| `Ctrl + K, Z` | Zen mode (distraction free) |
| `Ctrl + K, Ctrl + S` | View all shortcuts |

## Editing
| Shortcut | Action |
|----------|--------|
| `Ctrl + D` | Select next occurrence of word |
| `Ctrl + Shift + L` | Select ALL occurrences |
| `Alt + Click` | Add multiple cursors |
| `Ctrl + Alt + Down/Up` | Multi-cursor above/below |
| `Alt + Up/Down` | Move line up/down |
| `Shift + Alt + Up/Down` | Duplicate line |
| `Ctrl + Shift + K` | Delete line |
| `Ctrl + /` | Toggle comment |
| `Shift + Alt + F` | Format document |
| `Ctrl + Space` | Trigger suggestions |
| `F2` | Rename symbol (all occurrences) |
| `Ctrl + H` | Find & Replace |
| `Ctrl + Z` | Undo |
| `Ctrl + Shift + Z` | Redo |
| `Ctrl + X` | Cut line (without selection) |
| `Ctrl + C` | Copy line (without selection) |
| `Tab` | Indent |
| `Shift + Tab` | Outdent |
| `Ctrl + ]` | Indent line |
| `Ctrl + [` | Outdent line |
| `Home / End` | Go to start/end of line |
| `Ctrl + Home / End` | Go to start/end of file |

## Navigation
| Shortcut | Action |
|----------|--------|
| `Ctrl + G` | Go to line number |
| `Ctrl + Click` | Go to definition |
| `F12` | Go to definition |
| `Alt + F12` | Peek definition |
| `Ctrl + -` | Go back |
| `Ctrl + Shift + -` | Go forward |
| `Ctrl + Tab` | Switch open files |
| `Ctrl + 1 / 2 / 3` | Focus editor group |
| `Ctrl + \` | Split editor |
| `Ctrl + W` | Close tab |
| `Ctrl + Shift + T` | Reopen closed tab |

## Terminal
| Shortcut | Action |
|----------|--------|
| `Ctrl + `` ` | Open/close terminal |
| `Ctrl + Shift + `` ` | New terminal |
| `Ctrl + C` | Kill running process |
| `Alt + Up/Down` | Scroll terminal |

## Emmet (HTML fast typing)
```
div.container>ul>li*5         → div with ul and 5 li
nav>a*3                        → nav with 3 anchors
h1+p+a                         → h1, p, a siblings
.card>.card-title+.card-body   → nested with classes
input[type=email placeholder=Email]
!                               → full HTML boilerplate
```

## Must-Have Extensions
```
- Prettier              → Code formatter
- ESLint               → JS linting
- GitLens              → Git superpowers
- Live Server          → Auto-reload browser
- Auto Rename Tag      → Rename HTML tags in pairs
- Path Intellisense    → Autocomplete file paths
- Thunder Client       → API testing (like Postman)
- Bracket Pair Colorizer → Colored brackets
- Material Icon Theme  → Better file icons
- One Dark Pro         → Best dark theme
```
